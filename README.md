# 四象限记事本

一个基于艾森豪威尔矩阵（四象限时间管理法）的纯前端待办事项管理工具。整个程序只有一个 HTML 文件，双击即可在浏览器中打开使用，无需安装、无需联网、无需后端服务。

- 文件名：`四象限记事本.html`
- 文件大小：约 24 KB
- 技术栈：原生 HTML + CSS + JavaScript，零框架、零第三方库
- 数据存储：浏览器 localStorage（本地存储，不上传任何服务器）

---

## 一、设计理念

工具的核心是把"事情多、不知道先做哪个"的困境，转化为一个二维判断：这件事**重要**吗？这件事**紧急**吗？两个问题各回答一次，任务就自动落到四个格子之一，处理策略也随之确定。

内置的"分类方法理论"面板给出了完整出处：该方法源自美国第 34 任总统德怀特·D·艾森豪威尔 1954 年在美国西北大学演讲中引用的一位大学校长的话——"我有两类问题：紧急的和重要的。紧急的往往不重要，而重要的从来都不紧急。"后来史蒂芬·柯维在《高效能人士的七个习惯》"习惯三：要事第一"以及《要事第一》中将其系统化为"时间管理矩阵"，使之广为流传。

四个象限与对应策略：

| 象限 | 位置 | 配色 | 策略 |
| --- | --- | --- | --- |
| 重要 · 紧急 | 右上 | 浅红 `#fde2e2` | 立即做——危机、临近截止的项目、突发问题 |
| 重要 · 不紧急 | 右下 | 浅蓝 `#e0f0ff` | 计划做——学习成长、长期规划、锻炼健康、人际关系 |
| 不重要 · 紧急 | 左上 | 浅橙 `#fff4e0` | 授权做 / 尽量少做——某些电话、会议、他人的临时请求 |
| 不重要 · 不紧急 | 左下 | 浅灰 `#ececec` | 不做 / 删除——无意义刷手机、闲聊、消遣过度 |

柯维的观点是：把最多精力投入"重要不紧急"，提前规划，才能减少"重要且紧急"的危机，从被动救火转为主动掌控。

## 二、界面结构

### 1. 左侧任务栏

深蓝色（`#2c3e50`）固定侧边栏，宽 220px，自上而下排列：

- 标题：四象限记事本
- 增加事项
- 减少事项
- 修改事项
- 生成 To Do List
- 排序：（按钮文字会随当前模式变化）
- 分类方法理论
- 底部提示：点击事项卡片可查看详情、修改事件；提醒功能需保持本页面打开

按钮平时为深灰蓝（`#34495e`），悬停变亮（`#4a6785`），"减少事项"进入删除模式后变为红色（`#c0392b`）并保持高亮。

### 2. 右侧四象限主区

主区域用 CSS Grid 切成 2×2 四等分，格子间距 16px。上面覆盖一层用绝对定位绘制的十字坐标轴：横轴、纵轴均为 3px 深色实线，轴端用 CSS 伪元素画出三角箭头，四个方向分别标注"重要""不重要""紧急""不紧急"。

每个象限是一个圆角 10px 的色块，标题栏写明象限名称，下方是事项列表，内容超出时该象限内部独立滚动，不会撑破整体布局。

### 3. 事项卡片

白底、圆角 6px、浅阴影，鼠标悬停阴影加深。卡面显示：

- 第一行：事件描述（加粗，长文本自动换行断词）
- 第二行：截止时间 + 倒计时
  - 未到期显示绿色"剩余 X天X小时X分"
  - 已到期显示红色加粗"已逾期 X天X小时X分"
- 若设置了提醒，追加一个铃铛图标和最近一个提醒时间；有多个提醒时显示"等 N 个提醒"

点击卡片弹出详情窗，依次展示：分类、截止时间（含倒计时）、全部提醒时间（已提醒过的会标注"已提醒"）、备注（保留原有换行）。详情窗右上角可直接跳转到"修改事件"。

## 三、功能说明

### 1. 增加事项

点击"增加事项"打开表单，字段如下：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 事件描述 | 必填 | 为空时提示"请输入事件描述"并阻止保存 |
| 截止日期 | 必填 | 年 / 月 / 日 / 时 / 分 五个下拉框 |
| 重要性 | 必填 | 单选，默认"重要" |
| 紧急性 | 必填 | 单选，默认"紧急" |
| 提醒时间 | 可选 | 可添加多个，每个都能单独删除 |
| 备注 | 可选 | 多行文本框 |

两个细节值得说明：

- **日期选择器**不是系统自带的日期输入框，而是自建的五个下拉框。选择年份或月份时会自动重算当月天数并重绘"日"的选项，所以 2 月只有 28 或 29 天、4 月只有 30 天，不会出现无效日期。年份范围从"去年"或"已有年份的较早者"起，到"今年 + 10"。
- **倒计时预览**：表单下方实时显示"剩余……"，随下拉框改动即时刷新，填时间时就能看到还剩多久。

新增提醒的默认值规则：第 N 个提醒默认取"截止时间前 N 小时"。如果算出来的时间已经过去，则改为当前时间之后 1 小时，避免一保存就触发。

### 2. 减少事项

点击后进入"删除模式"：

- 页面顶部浮出红色提示条"勾选要删除的事项"，带"删除所选""取消"两个按钮
- 所有卡片左侧露出复选框（平时隐藏）
- 此时点击卡片是勾选/取消勾选，不会打开详情

点击"删除所选"会先检查是否至少勾选了一项（否则提示"请先勾选要删除的事项"），再二次确认"确定删除 N 个事项？"，确认后批量删除、保存、退出删除模式。点"取消"直接退出，不删任何东西。

### 3. 修改事项

由于卡片分散在四个象限里，修改入口设计成"先选后改"：点击"修改事项"先弹出一个列表，把所有事项按四象限分组列出，每条显示事件描述、分类、截止时间；点击其中一条即可进入编辑表单。

编辑表单与新增表单完全共用一套界面和校验逻辑，只是标题变为"修改事项"、按钮变为"保存修改"，并把原有的描述、截止时间、重要性、紧急性、全部提醒、备注回填。保存后按新的重要/紧急属性自动移动到对应象限。

### 4. 生成 To Do List

点击后生成一份按策略优先级排列的清单，分组顺序固定为：

1. 重要且紧急（立即做）
2. 重要不紧急（计划做）
3. 不重要紧急（授权做）
4. 不重要不紧急（尽量不做）

组内按**截止时间升序**排列，每条带序号、截止时间、剩余/逾期时间，有备注的追加备注。空分组显示"无"。

底部两个按钮：

- **复制文本**：把清单转成纯文本写入剪贴板，格式为"To Do List + 【象限名】+ 1. 事项 截止……（剩余……）备注……"；若浏览器拒绝剪贴板权限，会退化为弹出文本框让用户手动复制
- **打印**：新开一个空白窗口，只写入清单内容并立即调用打印，不会把整个四象限界面打进去

### 5. 排序切换

按钮文字在"排序：输入顺序"与"排序：截止时间"之间切换，点击即换，选择结果保存到 localStorage，下次打开仍是上次的选择。

- 输入顺序：按创建时间（`createdAt`）升序，即你添加的先后
- 截止时间：按 deadline 升序，越急的越靠上

### 6. 分类方法理论

内置一份完整科普面板，包含：方法出处（艾森豪威尔 1954 年演讲原话及中译）、柯维的推广著作、重要性与紧急性的定义、四象限逐一处理策略、核心思想总结。适合给第一次接触四象限法的人做入门阅读，也可作为演示材料。

## 四、提醒机制

每个事项可以挂多个提醒时间，彼此独立。页面每 **15 秒**轮询一次：

1. 遍历所有事项，筛出"未完成且时间已到"的提醒
2. 把这些提醒逐条标记为已完成（`done = true`），避免重复提醒
3. 保存数据并重新渲染，卡片上的铃铛信息同步更新
4. 播放提示音：用 Web Audio API 现场合成三声 880Hz 正弦波，间隔 0.35 秒，每声持续 0.2 秒，不依赖任何音频文件
5. 若用户已授权浏览器通知权限，同时弹出系统通知，标题为"事项提醒"，正文含事件描述、截止时间与倒计时
6. 无论如何再弹一个 alert，汇总本次所有到期事项

首次打开页面时，如果通知权限处于"未决定"状态，会主动申请一次。

需要明确的是：这是**页面级提醒**，不是后台服务。浏览器标签页关闭或电脑休眠时不会触发，所以侧边栏底部特意写了"提醒功能需保持本页面打开"。修改某个提醒的时间后，该提醒会被重置为未提醒状态，到点会重新响。

## 五、数据结构

每条事项是一个对象：

```json
{
  "id": "m1abc2def3ghi",
  "createdAt": 1698765432100,
  "desc": "写课程论文初稿",
  "deadline": "2026-10-25T18:00",
  "important": true,
  "urgent": false,
  "note": "先列提纲再动笔",
  "reminders": [
    { "at": "2026-10-25T09:00", "done": false },
    { "at": "2026-10-25T15:00", "done": false }
  ]
}
```

字段含义：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 时间戳转 36 进制 + 4 位随机串，保证唯一 |
| createdAt | number | 创建时的时间戳，用于"输入顺序"排序 |
| desc | string | 事件描述 |
| deadline | string | `YYYY-MM-DDTHH:MM` 格式的截止时间 |
| important | boolean | 是否重要 |
| urgent | boolean | 是否紧急 |
| note | string | 备注 |
| reminders | array | 提醒列表，每项含 `at`（时间）与 `done`（是否已提醒） |

localStorage 使用两个键：

- `eisenhower_tasks`：全部事项的 JSON 数组
- `eisenhower_sort`：排序偏好，`input` 或 `deadline`

代码里还保留了旧数据兼容逻辑：早期版本只有单个 `remindAt` 和 `reminded` 字段，加载时若检测到没有 `reminders`，会自动转换成数组格式并删除旧字段，保证老用户升级后数据不丢。

## 六、技术实现要点

- **纯原生实现**：无 Vue、React、jQuery 等任何依赖，单个 HTML 文件即可运行，便于拷贝、分享、离线使用
- **布局**：CSS Grid 做四象限，绝对定位 + 伪元素做坐标轴，`flex` 做侧边栏与卡片内部排版
- **即时重算**：表单里的倒计时预览随下拉框 `onchange` 实时更新；主界面每 30 秒自动重渲染一次，让"剩余时间"不会长期停在旧数字上（删除模式下暂停刷新，避免打乱勾选）
- **安全处理**：用户输入（描述、备注）在插入 DOM 前统一经过转义函数，替换 `& < > " '` 五个字符，防止把 HTML 标签当代码执行（XSS）
- **提醒音**：Web Audio API 的 `OscillatorNode` + `GainNode`，无外部资源
- **打印优化**：单独开窗口写入精简 HTML 再打印，只输出清单本身
- **浏览器兼容**：使用 `navigator.clipboard`、`Notification`、`AudioContext` 等现代 API，并都做了可用性判断与降级处理（例如剪贴板失败时退回手动复制），在主流现代浏览器（Chrome、Edge、Firefox）中均可正常使用

## 七、使用说明

1. 双击 `四象限记事本.html`，用浏览器打开（建议 Chrome 或 Edge）
2. 首次打开时若弹出通知权限请求，选择"允许"，提醒才能同时发系统通知
3. 点"增加事项"，填写描述、选截止时间、选重要/紧急、按需加提醒，保存后事项自动落到对应象限
4. 日常使用中点卡片看详情、点"修改事项"改内容、点"减少事项"清理已完成项
5. 每天开始工作前点"生成 To Do List"，按清单从第一象限做起
6. 关闭浏览器后数据仍在（存在 localStorage），下次打开继续

## 八、已知局限

- 数据只保存在**当前浏览器 + 当前文件路径**对应的 localStorage 中，换浏览器、换电脑、清除浏览器缓存都会丢失；没有导入/导出功能，也没有多设备同步
- 提醒依赖页面保持打开，关闭标签页后不生效，不具备后台常驻能力
- 时间精度到分钟，不支持秒级提醒
- 没有完成状态标记，事项处理完需要通过"减少事项"删除
- 没有搜索、筛选、标签、子任务、重复任务等进阶功能
- 单文件结构中所有样式与脚本内联，代码量再增长时维护性会下降
